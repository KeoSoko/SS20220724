Objective

Fix the two confirmed privacy risks while making the smallest possible production change.

These fixes are independent of the wider Billing Group migration and should be deployed first.

Task 1A – Tax Report Isolation

File:
server/tax-service.ts

Affected methods:

getTaxDashboard(userId)
generateTaxReport(userId, year)
getTaxYearReceipts(userId, year)

Current behaviour:

Resolves workspaceId from userId
Queries receipts using workspace_id

Required behaviour:

Query receipts using user_id directly
Remove dependency on workspace ownership for tax data

Expected outcome:

User A tax reports contain only User A receipts.

User B receipts never appear in User A tax outputs.

Task 1B – Email Document Isolation

File:
server/routes.ts

Affected endpoints:

GET /api/email-documents/:id/download
GET /api/email-documents/:id/view

Current behaviour:

if (doc.workspaceId !== user.workspaceId)

Required behaviour:

if (doc.userId !== user.id)

Expected outcome:

Users can only view or download their own email documents.

Members of the same billing group cannot access each other's email receipts or raw HTML emails.
